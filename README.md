# To-Do List

## Descripción
Aplicación de consola que permite gestionar una lista de tareas: crearlas, listarlas y marcarlas como completadas.

## Lenguaje
JavaScript (Node.js)

## Funciones
- `agregarTarea`: Agrega una nueva tarea a la lista
- `listarTareas`: Muestra todas las tareas con su estado
- `completarTarea`: Marca una tarea como completada

## Como ejecutar
```
node index.js
```
